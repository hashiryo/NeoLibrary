0 か 1 の値を取る変数について、1 変数の項と 2 変数の項の和の最小を求めます。項は値の表で渡します。劣モジュラでない 2 変数の項も、変数の 0 と 1 の入れ替えで直せるなら、入れ替えを自動で探して解きます。

```cpp
template <class Cost> class BinaryOptimization {
  explicit BinaryOptimization(int n = 0);
  int add_variable();
  void add(Cost c);                                                // 定数
  void add(int i, Cost c0, Cost c1);                               // x_i が 0 なら c0、1 なら c1
  void add(int i, int j, Cost c00, Cost c01, Cost c10, Cost c11);  // (x_i, x_j) が (0, 0) なら c00、(0, 1) なら c01、...
  std::optional<Cost> solve();
  std::vector<int> argmin();
};
```

変数は 0 から n - 1 の番号で、`add_variable()` で 1 つ足せます。同じ変数や同じ組に何度 `add` してもよく、項はすべて足し合わされます。`solve()` は和の最小を返し、`argmin()` は直前の `solve()` の最小を与える割り当てを返します。値だけを使うときは `argmin()` を呼ばなければ、その分の時間がかかりません。最大化は、費用の符号を反転して渡し、`solve()` の符号を戻します。

2 変数の項は、$c_{00} + c_{11} \le c_{01} + c_{10}$ (劣モジュラ) なら最小カットにそのまま載ります。そうでない項があっても、いくつかの変数の 0 と 1 を入れ替えて全部の項を劣モジュラにできるなら、その入れ替えを探して解きます。たとえば「隣り合うマスの色が違えば得点」の項は、格子を市松模様に入れ替えれば劣モジュラになるので、問題文のまま書けます。行と列のように二部に分かれた変数どうしの項も同じです。どう入れ替えても直らないときは、`solve()` が `nullopt` を返し、`argmin()` は空になります。

禁止したい割り当てには、大きな費用を置きます。1e18 や $2^{62}$ でもかまいません。`Cost` は整数の型で、和は中で 128 bit で数えます。最小が `Cost` に収まらないとき (どの割り当ても禁止の費用を踏むときなど) は、`Cost` の最大か最小に丸めた値を返します。計算量は、頂点 n + 2 個と、劣モジュラな 2 変数の項ごとに辺 1 本の網の最小カット 1 回です。

## 中身

変数ごとに頂点を 1 つ置き、x = 1 を t の側とします。2 変数の項は、1 次の部分と、両向きの辺 1 本に分けます。分け方は、1 次の部分の増分ができるだけ 0 に近くなるものを選びます。そうすると、禁止のために置いた大きな値は辺の容量に入り、定数の項へ漏れません。入れ替えは、劣モジュラな項は両端を同じに、そうでない項は逆にする、という制約を、重み付きの union-find で 2 色に塗って決めます。

最小カットは [最大流](MaxFlow.md) で求めます。自明なカット (全部 0、全部 1、1 変数の項だけで最小になる割り当て) の値の最小を上界とし、それより大きい容量は上界 + 1 に縮めて、64 bit の容量で流します。上界が $2^{61}$ 以上のときだけ、128 bit の容量で流します。GNU の拡張が無く、`__int128` が整数の型と見なされない環境 (`-std=c++20` など) では、128 bit で流す代わりに 64 bit で $2^{61}$ まで流すので、最小カットがそれを超えると正しい値になりません。

小さい乱択の入力 (入れ替えで直るもの、直らないもの、1e18 と $2^{62}$ の禁止を混ぜたもの) で、総当たりと 90 万回ほど突き合わせました。procon-judge では、ABC 193 F (市松模様の入れ替えと、色の決まったマスの強制)、ARC 085 E (倍数について閉じた集合の禁止)、ABC 259 G (行と列の入れ替えと、負のマスの禁止) で確かめています。どれもテストデータは自作です。記録は algo-notes の notes/network-flow.md にあります。
