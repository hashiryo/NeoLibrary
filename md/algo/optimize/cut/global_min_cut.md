無向グラフの頂点を 2 つの空でない集合に分けたとき、間を渡る辺の重みの和の最小 (全域最小カット) を求めます。

```cpp
template <class Cap> Cap global_min_cut(int n, const std::vector<std::tuple<int, int, Cap>>& edges);
```

頂点 n 個と、無向辺 {u, v, 重み} の列を受けます。辺の受け方は gomory_hu と同じです。`Cap` は整数の型で、重みは 0 以上、各頂点の重み付きの次数が `Cap` に収まる必要があります。多重辺、自己ループ (使いません)、重み 0 の辺があってもかまいません。つながっていなければ 0 を返し、n が 1 以下でも 0 を返します。

返すのは値だけです。カットの片側の頂点集合は返しません。

## 中身

Nagamochi-Ono-Ibaraki の方法で求めます。最小カットの上界 λ を、重み付きの次数の最小から始めます。

1. maximum adjacency の順 (なめた頂点への重みの和 r が最大の頂点から順) に頂点をなめます。頂点 v をなめたとき、隣の未訪問の w の r(w) が λ を越えたら、v と w をまとめます。r(w) は v と w の局所連結度の下界なので、λ より小さいカットは v と w を分けません。
2. なめた頂点の集合のカットの値を足し引きで持ち、λ を下げます。
3. 1 回なめたら、まとめた頂点を縮めて多重辺を足し、頂点が 1 つになるまで繰り返します。まとまる組が無ければ、Stoer-Wagner の方法と同じく最後の 2 頂点をまとめます。

なめる前には、Padberg-Rinaldi の 2 つの条件で縮めます。重みが λ 以上の辺と、2 c(u, v) > min(deg u, deg v) の辺です。後者の等号を除くのは、条件を満たす辺をまとめて縮めても最小カットを壊さないためです。

今のグラフが疎なうちは、隣接の列と 2 分ヒープでなめます。辺の数 × 20 が頂点の数の 2 乗以上で、頂点が 4096 以下になったら隣接行列に移り、最大の r を持つ頂点を毎回なめて選びます。1 回のなめは O(k^2) (k は今の頂点の数) で、行列の Stoer-Wagner の方法と同じ手間で、縮める組がそれ以上になります。縮めるうちに密になったグラフも、行列で仕上げます。

重みがどれも等しい完全グラフのように、どの辺も上界にちょうど届くのが最後の頂点だけのグラフでは、1 回のなめで縮むのが 1 組ほどで、行列の Stoer-Wagner の方法と同じく O(n^3) かかります。

procon-judge の 4 問で書き比べました。x64-gcc (Xeon 6975P-C) のアルゴリズムの時間の最大と合計です (run 44310927690)。行列の Stoer-Wagner の方法、隣接の列とヒープだけで回す形、gomory_hu で Gomory-Hu 木を作って辺の重みの最小を答える形と並べています。

| 問題 | 大きさ | この形 | 行列の Stoer-Wagner | ヒープだけ | gomory_hu |
| --- | --- | --- | --- | --- | --- |
| luogu-P5632 (12 ケース) | 頂点 600、辺 18 万本まで | 116.7 / 171.3 ms | 139.3 / 1509.0 ms | 2673.2 / 2979.2 ms | 618.8 / 1295.5 ms |
| hdu-6081 (12 ケース) | 頂点 3000、辺 10^5 本 | 98.8 / 490.1 ms | なし | 2056.9 / 2463.4 ms | なし |
| poj-2914 (8 ケース) | 頂点 500 | 259.8 / 321.5 ms | 740.8 / 2470.4 ms | なし | 748.2 / 1106.1 ms |
| hdu-3691 (8 ケース) | 頂点 300 | 77.6 / 123.5 ms | 158.4 / 561.4 ms | なし | 186.0 / 474.7 ms |

どの問題でも、最大のケースは重みがどれも等しい完全グラフです。ヒープだけの形は、そのケースで隣接の列を頂点の数ほど繰り返しなめるので、行列の形の 20 倍ほどかかります。この回のあと、始めから密な入力では隣接の列を組まずに行列で解くようにしました。測り直した回 (run 44329251909) では、luogu-P5632 が同じ Xeon 6975P-C の x64-gcc で 112.6 / 149.8 ms になり、行列だけで回す形 (107.9 / 146.6 ms) と並びました。
