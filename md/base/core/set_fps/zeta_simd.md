---
title: ゼータ変換の AVX2 の核 (内部)
documentation_of: ../../neo/base/core/set_fps/zeta_simd.hpp
---

`sps` のゼータ変換・メビウス変換・アダマール変換が、値が 4 byte か 8 byte で、列が 32 byte 以上のときに呼ぶ内部の核です。直接は使いません。

- 値は 32 byte の塊 (4 byte なら 8 個、8 byte なら 4 個) ごとに、1 本の `__m256i` に読む。塊の中の bit (4 byte なら下の 3 bit、8 byte なら 2 bit) は、レーンをずらした値と混ぜて済ませる。
- 塊をまたぐ bit は、塊の列を半分か 4 分の 1 に分けて再帰してから合わせる。下の段は L1 と L2 の中で済み、4 つに分けたときは 2 段を 1 回の読み書きで合わせる。bit ごとの変換は互いに可換なので、段の順は結果に効かない。
- 演算は、`ZMod` の足し算と引き算、整数の足し算と引き算、32 bit の max と min (符号付きと符号なし)、64 bit の max と min を持つ。`ZMod` の値は $2M$ 未満のそのままの値で、結果は `ZMod` の `+=` や `-=` で求めた値に一致する。64 bit の max と min は AVX2 に命令が無いので、`cmpgt` で比べて混ぜる。
- 演算 (法の定数などを持つ) は値で受け、関数の中の手元の変数にする。参照のままだと、`__m256i` の書き込みのたびに gcc が定数をメモリから読み直す。
