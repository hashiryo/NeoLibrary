32 bit と 64 bit の整数の型 (符号付きも) のときに、`sps::exp` と `sps::log` が呼ぶ内部の核です。直接は使いません。値は法 $2^{64}$ で求め、32 bit の型は求めてから切り詰めます。法 $2^{64}$ では $1/k$ が無く、XOR 変換の逆変換の $2^{-n}$ も無いので、[ranked_xor.hpp](ranked_xor.md) は使えません。

## OR のランク付きのゼータ変換

$f[S]$ を $f[S]\, t^{|S|}$ に置いて OR 畳み込みをすると、$t^{|U|}$ の係数は互いに素な組 ($S \cup T = U$、$S \cap T = \emptyset$) だけの和、すなわち部分集合畳み込みになります。重なる組から出る項は rank が集合の大きさより大きく、足し算と掛け算のどちらを通しても大きいままです。そのため XOR 変換と同じく、上の要素から 1 つずつ足す再帰を変換の領域の各点の計算として書けます。$f_i[S'] = f[S' \cup \{i\}]$ とします。

- exp: 変換の領域で $\hat{H}[y \cup \{i\}] = \hat{H}[y] (1 + t \hat{f}_i[y])$ を上の要素から順に求める。
- log: 段ごとに $t \hat{f}_i / \hat{f}_{<i}$ を各点の冪級数の割り算 (定数項は 1) で求め、$i$ bit の逆変換をする。

どちらも割り算 (整数での割り算) を使わず、逆変換は最後に 1 回だけです。rank は $n$ までで切れます。XOR 変換と違って補集合の対称性が無いので、位置は $2^n$ 個要り、各位置は rank 0 から $n$ を全部持ちます。

## 持ち方

値は u64 で持ち、位置 4 個を 1 本の `__m256i` に並べます (塊は位置 4 個と rank の数の積)。下の 2 bit はレーンの中で変換します。下の bit から変換すると、値は rank が [残りの上の bit の数, それ + 済んだ bit の数 + 2] の範囲にしかないので、その範囲 (窓) だけを足し引きします。

位置の下の 11 bit (レーンの 2 bit と塊の 9 bit) を区画とし、区画の中の変換 (区画の段) は区画ごとに 2 段ずつ 1 回の読み書きで行います。上の bit は、下の 11 bit が同じ塊 (列) を作業の配列に集め、上の段の変換、各点の計算、上の段の逆変換を続けて行います。大きい配列の列 $c$ の塊は、区画の段の順変換の値 (区画の起点からの相対の rank 0 から $\mathrm{popcount}(c) + 2$) と、区画の段の逆変換に要る値 (相対の rank $\mathrm{popcount}(c)$ から 11) の多い方の幅だけを持ちます。区画の幅は 12 × 512 から 4470 に減ります。今の列を計算している間に、次の列の塊を L2 へ先に読みます。大きい配列には huge page を頼みます。

u64 の積の和は、$a_{lo} b_{lo}$ (vpmuludq) と、$(a_{lo} b_{hi}, a_{hi} b_{lo})$ の下位 32 bit (vpmulld、$b$ は 32 bit の半分を入れ替えて置く) を足して求めます。exp は隣り合う 2 つの出力をまとめて求め、片方の列の値をレジスタで次の項へ渡します。

$n < 13$ のときと区画 0 (下の 11 bit の部分) は、段ごとに $i$ bit の変換を 3 回する形で求めます。

## 速さ

procon-judge の洛谷 P13843 (exp) と P13844 (log) で書き比べました ($n = 20$)。汎用の道は、段ごとのランク付きのゼータ変換を値 1 つずつ行う形です。この核は書き比べの rz3 の写しです。

| 問題 | 書き比べの rz3 | 汎用の道 | 段ごとの形 (rz1) | CPU |
| --- | ---: | ---: | ---: | --- |
| exp (P13843) | 71.56 ms | 370.82 ms | 266.16 ms | Xeon 6975P-C |
| log (P13844) | 54.34 ms | 290.39 ms | 232.44 ms | EPYC 9V45 |

値は run 44300849581 の x64-gcc の algo の最大です。メモリの最大は、汎用の道の 187 MB から 98 MB に減りました。記録は algo-notes の notes/set-power-series.md にあります。
