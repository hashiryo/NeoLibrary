正方行列の逆行列を求めます。

```cpp
template <class T> std::optional<Matrix<T>> inverse(Matrix<T> A);
```

正則でなければ `std::nullopt` を返します。`T` は体で、`ZMod` なら法は素数でなければなりません。浮動小数点数では、列の中で絶対値が最大の値を要に選び、絶対値が $10^{-8}$ 以下なら 0 とみなします。$n \times n$ の行列に $O(n^3)$ の時間がかかります。

## 中身

$[A \mid I]$ を前進消去すると、要の行が $[T \mid Y]$ ($T$ は上三角で $YA = T$) になるので、$TX = Y$ を後退代入で解きます。`ZMod` の前進消去は `det` と同じ遅らせた更新です。

右半分の列は、「行 $r$ の単位行列の 1 の位置」として付け替えます。行を $t$ 番目の要にするとき、その行の 1 を位置 $t$ に移し、位置 $t$ にあった行の 1 を空いた位置に移します。その 2 つの位置には、まだ持ち主の行にしか値がありません。なので、この移し替えは右半分の列の入れ替えと同じです。すると要の行の右半分は位置 $t$ 以下にしか値がなく、残りの行の更新は、今の列から $n$ + (要の数) の手前までの列で済みます。前進消去の手間は $5n^3/6$ から $n^3/2$ に減ります。後退代入は `solve` と同じく、下から 8 行ずつの組にします。$n \le 16$ の `ZMod` とほかの体は、素朴な掃き出しにします。

procon-judge の yosupo-inverse-matrix で書き比べた zmod_inv_relabel を写しました。写し元は x64-gcc の Xeon 8573C で 21.56 ms と首位で、前の形 (zmod_inv_blk8t) の 28.61 ms から 25% 減りました。lib-neo の提出は、手元の M2 で写し元と 2% から 4% の差でした。記録は algo-notes の notes/linear-algebra.md にあります。
