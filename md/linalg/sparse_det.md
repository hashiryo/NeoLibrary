疎な $n \times n$ 行列の行列式を求めます。

```cpp
template <class T> T sparse_det(int n, const std::vector<std::tuple<int, int, T>>& entries);
```

成分は (行, 列, 値) の列で渡し、同じ位置が複数あれば和を取ります。`T` は `ZMod` で、法は素数でなければなりません。ほかの型は密な行列にして `det` を呼びます。0 でない成分の数を $K$ として、乱択がはずれなければ $O(n (n + K))$ の時間がかかります。

返す値はいつも正しく、乱択で変わるのは時間だけです。$A$ が正則なら、1 回の試行がはずれる確率は、法を $p$ として $n^2 / p$ 程度です。はずれたら乱数を選び直し、3 回続いたら密な行列の掃き出し ($O(n^3)$) にします。法が $10^9$ ほどで $n = 3000$ なら、はずれる確率は 1 回あたり 1% 未満です。法が小さく $n^2$ が $p$ より大きいときは、密な掃き出しになることが多くなります。法が 2 のときは、はじめから密な掃き出しにします。

## 中身

Wiedemann の方法です。乱択の対角行列 $D$ を右から掛けた $B = AD$ の列 $s_i = u^T B^i v$ ($i < 2n$、$u$ と $v$ も乱択) の最小多項式 $f$ を Berlekamp–Massey の方法で求めます。$f$ は $B$ の最小多項式を割り切るので、次数が $n$ なら $f$ は $B$ の特性多項式です。このとき $\det(B) = (-1)^n f(0)$ で、$\det(A) = \det(B) / \det(D)$ です。次数が $n$ 未満でも、$f(0) = 0$ なら $B$ は正則でなく、$\det(A) = 0$ と分かります。どちらでもないときが、乱択がはずれたときです。空の行か列があれば、すぐ 0 を返します。

行と列は、成分の数の多い順に同じ並べ替えで付け直し (相似変換なので行列式は変わりません)、行ごとに成分を続けて並べます (CSR)。長さの同じ行が続くので、行の内側のループの終わりの分岐が予測どおりになります。行の和は u64 にため、各行の和は畳んでから Montgomery の還元で $2^{-32}$ 倍して $M$ 未満に直します。毎回 $2^{-32}$ 倍するのは、$\lambda = 2^{-32}$ として $\lambda B$ の列を作るのと同じなので、$\det(\lambda B)$ を求めてから $\lambda^{-n}$ を掛けて戻します。Berlekamp–Massey の方法のずれの内積と、漸化式の更新 (Shoup の方法) も 4 個ずつまとめます。

procon-judge の yosupo-sparse-matrix-det で書き比べた zmod_wiedemann_csr を写しました。写し元は x64-gcc の EPYC 7763 で 73.58 ms と首位で、今の Library の 5.7 倍の速さです。lib-neo の提出は、手元の M2 で写し元と並びました。写し元は次数が $n$ 未満なら 0 を返すので、正則な行列でも乱択がはずれると 0 を返します ($n = 3000$ の単位行列で 0.45% ほど)。記録は algo-notes の notes/linear-algebra.md にあります。
