対角が 0 の $n \times n$ の対称行列 $A$ のハフニアン $\mathrm{haf}(A)$ を求めます。$A$ を頂点 $n$ 個の完全グラフの辺の重みとみたときの、完全マッチングの重み (辺の重みの積) の和です。

```cpp
template <class T> T hafnian(const Matrix<T>& A);
```

$n$ が奇数なら 0、$n = 0$ なら 1 を返します。対角と、対角より下の成分は読みません ($i < j$ の $a_{ij}$ だけを使います)。`T` は和と積と 0 と 1 を持つ可換環であればよく、$n$ は 62 以下です。手間は $O(2^{n/2} n^2)$ で、`T` が `ZMod` 以外か法が偶数の `ZMod` なら、$2^{n/2} n$ 個の `T` の領域を使います。

## 中身

頂点 $2p$ と $2p+1$ を組 $p$ ($p < h = n/2$) とします。完全マッチングに組の辺を重ねると交互の閉路に分かれるので、閉路を最大の組の小さい順に 1 本ずつ作ります。閉路は最大の組 $w$ の頂点 $2w$ から出ます。マッチングの辺で別の組の頂点 $k$ に入って組の辺で $k \oplus 1$ へ移ることを繰り返し、最後に $2w+1$ へ戻って閉じます。

$c[S]$ を、組の集合 $S$ をちょうど覆って閉路がすべて閉じた重みの和とします。$D_e[T]$ は、$S = \{w\} \cup T$ ($T \subseteq \{0, \ldots, w-1\}$) で、最大の組の閉路がいま頂点 $e$ で開いている重みの和です。層 $w$ の $T$ ごとに次の値を求めます。

<!-- textlint-disable ja-technical-writing/max-comma -->
$$v_T[k] = c[T]\, a_{2w,k} + \sum_{p \in T} \left( D_{2p}[T]\, a_{2p,k} + D_{2p+1}[T]\, a_{2p+1,k} \right)$$
<!-- textlint-enable ja-technical-writing/max-comma -->

$v_T[2w+1]$ が $c[S]$ です。$T$ に入らない組 $p$ へは、$D_{2p+1}[T + 2^p] = v_T[2p]$ と $D_{2p}[T + 2^p] = v_T[2p+1]$ を配ります。どの値も配る元は 1 つだけで、$T + 2^p > T$ なので、$T$ を小さい順に見れば読む前に書き終わっています。答えは $c[\{0, \ldots, h-1\}]$ です。

`ZMod` で法が奇数なら、$v_T$ を AVX2 で列の向きに 4 個ずつ求めます。隣接行列は Montgomery の表現で持ち、u64 の和にためて、8 項ごとに最上位の bit が立っていれば $2M \cdot 2^{32}$ を引き、最後に 1 回還元します。$D_e$ は頂点ごとの配列で、組 $p$ の頂点の配列は $T$ から bit $p$ を抜いた番号で引きます。$T$ を小さい順に見ると、どの配列も前から順に読み書きされます。

層 8 以上では、組を下の $\lfloor w/2 \rfloor$ 個と上の残りに分けます。上の組の部分集合ごとに、配る先の列 (下の組の頂点、上の組で $T$ に入らない組の頂点、$2w+1$) と使う行だけを並べた隣接行列を作り直し、下の組の部分集合を回します。全部の列を掛けると、積和の半分ほどを捨てるためです。ほかの `T` と法が偶数の `ZMod` は、同じ動的計画を要素の演算子で配る形にします。
